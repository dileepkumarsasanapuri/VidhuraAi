# ClaritySure AI

> **"Understand Your Insurance Before It Understands You."**

An AI-powered insurance intelligence platform that transforms complex insurance policies into personalized, scenario-based, multilingual, interactive explanations.

## 🏗️ Architecture

```
├── frontend/       # Next.js 15 + Tailwind CSS + Framer Motion
├── backend/        # Express.js REST API
└── README.md
```

## 🚀 Quick Start

### Frontend
```bash
cd frontend
npm install
npm run dev        # → http://localhost:3000
```

### Backend
```bash
cd backend
npm install
npm run dev        # → http://localhost:5000
```

## ✨ Features

| Product | Purpose |
|---------|---------|
| **PolicyLens AI** | Simplifies policy documents via OCR + NLP |
| **ClaimShield AI** | Predicts claim risks & outcomes |
| **CompareWise** | Intelligent policy comparison |
| **ScenarioGPT** | Real-life coverage Q&A |
| **TrustScore Engine** | Transparency scoring system |
| **ClaimCoach** | Guided claim filing assistance |
